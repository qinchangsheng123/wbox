# 01 视觉规范 · 僚机 Wingman v2.x

> 适用：设置面板、齿轮菜单、安装程序三态、图标板；落地为 Tkinter Canvas。文案归 Phase 2、预览归 Phase 3，`icons.svg` 另行绘制。

## 0. 结论先行

**选「分层」：品牌唯一实心 + 功能全线性**，不选全线性。16px 托盘/标题栏需实体剪影，纯线性会消失；功能层只要留填充口子，现状「实心/线性混用 + 镂空填背景色」必复发。硬规则锁死：**除 `mark` 外禁止任何 `fill`**（唯一例外 `dot`，见 §5）。

设计原则 5 条：
1. **一套语言、两层语义**：品牌唯一实心，功能全线性，不出现第二套填充语言。
2. **图标与底色解耦**：图标不画背景色像素；hover/主题只换 token、不换几何、不重绘。
3. **灰阶只靠明度分层**：只用 `fg/t2/t3/line` 四级明度，不加彩色。
4. **几何先于装饰**：只用可数清的直线段与整圆；**16px 是验收下限，细节在 16px 下消失即删**。
5. **面板与安装器共用一套组件**：不因 Canvas / ttk 差异产生第二套视觉。

## 1. 色板与字号（Phase 3 直接复用）

10 个 token 原值不动，写成 CSS 变量供 `preview.html` 使用：

```css
:root[data-theme=light]{--bg:#FFFFFF;--fg:#000000;--t2:#595959;--t3:#767676;
 --line:#E5E5E5;--border:#767676;--hover:#F5F5F5;--active:#EBEBEB;
 --inv:#000000;--invfg:#FFFFFF}
:root[data-theme=dark]{--bg:#000000;--fg:#FFFFFF;--t2:#B3B3B3;--t3:#8C8C8C;
 --line:#2A2A2A;--border:#8C8C8C;--hover:#141414;--active:#202020;
 --inv:#FFFFFF;--invfg:#000000}
```

对比度（`文字/底`）：light `fg` 21:1、`t2` 7.0:1、`t3` 4.54:1；dark 21:1/10.0:1/6.2:1，均达标。`border` 与 `t3` 同值，**禁用 `--border` 画文字**；`line` 仅作分隔线（约 1.2:1，不承载文字）。

字号阶梯（Microsoft YaHei UI → YaHei → Segoe UI，负号像素字号），最多 6 级，禁止堆砌：

| 级 | 96dpi | 字重 | 行高 | 用途 | 色 |
|---|---|---|---|---|---|
| D1 | -22 | Bold | 32 | 安装器大标题 | fg |
| H1 | -16 | Bold | 24 | 面板头部「僚机 Wingman」 | fg |
| H2 | -13 | Bold | 20 | 功能行名称、弹框标题 | fg |
| B1 | -12 | Regular | 18 | 菜单项、正文、按钮 | fg |
| B2 | -11 | Regular | 16 | hint、版本号、副标题 | t3 |
| C1 | -11 Consolas | Regular | 16 | 安装日志（等宽） | t2 |
| C2 | -10 | Regular | 14 | 底部 `v2.1.1 · 开关即时生效` | t3 |

换算 `fs(d) = -round(|s| × d/96)`，例 B1 `-12 → -12/-15/-18/-21/-24/-30`。

## 2. 统一图标语言（回答「分层怎么落地」）

**设计坐标**：功能/菜单 24×24、品牌盾 64×64。**统一光学框 20×20、安全边距 2**，外接框落在 `x,y ∈ [2,22]`（盾 `[8,56]`）。修掉现状「link 21.5 宽 / shield 16.4 / block 18」——**禁止不同图标占不同宽度**，轻重只靠笔画密度。

**线宽**：`lw = max(1, round(1.8 × s/24))`，`s` 为 DPI 缩放后的实际像素尺寸，结果必须取整像素（Canvas 无抗锯齿，小数线宽会糊）。96dpi 基准：16px→1、20px→2、22px→2、28px→2、32px→2；240dpi 的 22px→4。

**端点与圆角**：图标层一律 **方端（butt cap）+ 尖角（miter join）**，禁止 `capstyle=ROUND`、`smooth=True`、圆帽、圆角——无抗锯齿下圆端会退化成锯齿块。**组件层例外**：开关胶囊允许 `r = 短边/2`，但必须用「2 个 `create_oval` + 1 个 `rectangle`」拼，不得依赖 `roundrect`；按钮、卡片、弹框**一律直角**。

**替代「镂空填背景色」的方案（核心）**：所有图标遵守三不画 —— 不画背景色、不用背景色伪造镂空、不为状态存第二份几何。品牌盾的负形由「分块实心、空隙不绘制」产生（§3）；线性图标只画 `fg/t2/t3` 的线段，没画的地方天然透出真实底色。因此 hover 时**只重画所在行的矩形底**，不调用任何 `set_bg()`，图标无需重绘。

**状态 → 颜色映射**（只换 token，几何不变）：

| 状态 | 功能图标 | 底色 | 品牌盾 |
|---|---|---|---|
| 默认 | `t2` | `bg` | 恒 `fg` |
| hover | `fg` | `hover` | 恒 `fg` |
| active | `fg` | `active` | 恒 `fg` |
| disabled/只读 | `t3` | `bg` | `t3`（置灰态） |
| 勾选/选中 | `fg` | — | — |
| 反色容器内（Tooltip/开关） | `invfg` | `inv` | — |

**双主题**：几何逐字节相同，只翻 §1 token 表。**禁止**为 light/dark 写两套几何、镜像、翻转或改线宽。**避免**：`create_polygon(fill=<bg>)`、`stipple`、半透明、同一 glyph 混用 fill 与 outline（`mark` 除外）、hover 单独存几何。

## 3. 品牌盾新几何（64×64）

改为**三块纯实心 polygon，V 形留白由「不绘制」产生**，全部 `fill=fg`、无描边、无背景色：

| 块 | 坐标点（Tkinter 直接可用） |
|---|---|
| 顶桥 | (8,8) (56,8) (56,16) (8,16) |
| 左翼 | (8,16) (28,16) (28,32) (32,56) (8,32) |
| 右翼 | (36,16) (56,16) (56,32) (32,56) (36,32) |

等价 SVG path：`M8 8H56V16H8Z M8 16H28V32L32 56L8 32Z M36 16H56V32L32 56L36 32Z`

外框 = (8,8)-(56,8)-(56,32)-(32,56)-(8,32)，上下左右各留 8 单位，对称。V 形留白 = `y=16..32` 的 8 单位宽竖沟 + `y=32..56` 由两条斜边收口到 (32,56) 的倒三角，贯通、连续。

**改了什么**：旧「实心盾 + 用背景色画的上箭头镂空」换成「分块实心 + 向下收口的 V 形双翼留白」。上箭头（加力起飞）→ 双翼向下锚定；盾 = 守护，对称双翼 = 主副机编队伴飞，贴合「僚机/守护」，不再是起飞。

**为什么 16px 更清晰**：旧上箭头是窄描边细形（3–4 单位 → 16px 下 <1px），与盾边缘间距 <2 单位，缩放后粘连、且依赖背景色（深色标题栏/白底不一致）。新版沟宽 8 单位 → 16px 下 2px，与边缘间距 ≥8，是**几何负形而非一根线**；外框保留完整实心剪影，内部细节全丢时 16px 仍是可识别的盾。**避免**：圆角、内描边、第二层符号、渐变。

## 4. 四个功能图标差异化（现状 `link` 重复，必须拆）

全部线性、24×24、光学框 `[2,22]`、线宽按 §2。新增 `plane`、`pulse` 两个 kind，`shield`/`block` 保留原名只重画几何 —— 插件注册表只需把两行 `icon` 从 `link` 改为 `plane` / `pulse`，改动最小。

| 插件 | kind | SVG path / 坐标 | 一眼区分点 |
|---|---|---|---|
| 小飞机关联启动 | `plane`（新） | `M2 11L22 3L15 21L11.5 14.5Z` + 中脊 `M11.5 14.5L22 3` | 唯一有朝右上的锐角尖端（纸飞机＝随游戏拉起） |
| 游戏加加联动 | `pulse`（新） | 屏框 `M3 5H21V19H3Z` + 折线 `M5.5 14.5H9L11 9.5L13.5 17L15.5 12.5H19` | 唯一含折线脉冲（＝OSD 性能监控联动） |
| ACE 防护 | `shield`（重画） | 六边盾 `M12 2L21 6V13L12 22L3 13V6Z` + 对勾 `M8 12L11 15L16 9` | 唯一盾形＋勾（＝已防护/四道闸门已验证） |
| 弹窗关闭 | `block`（重画） | 窗口 `M2 7H15.5V20H2Z` + 顶栏 `M2 11H15.5` + 右上独立叉 `M17 3L22 8` `M22 3L17 8` | 唯一「框外带叉」（＝窗口一露面即关掉） |

与品牌盾区分：`mark` 实心分块 + V 留白、无勾；`shield` 线性轮廓 + 勾，不撞。`pulse`/`log`/`cfg` 矩形区分：框内折线 / 三横线 / 无外框。全部 path 只用 `M/H/V/L/Z`，**无 `C/Q/A` 曲线**。

## 7. 硬约束 / 可协商

**硬约束（不可动）**
1. 纯中性灰阶零彩色，仅用 §1 的 10 个 token；禁止任何 HEX 硬编码色（含 `#555`、`#f4f4f4`）。
2. 绘图原语仅限 `line / polygon / oval / arc / rectangle / text`；禁渐变、阴影、抗锯齿、SVG 运行时、贝塞尔/曲线、`roundrect`、`stipple`、半透明。
3. 双主题几何逐字节相同，只翻 token；禁止两套几何。
4. 六档 DPI 全部走 `px(v)=round(v×d/96)`；线宽、字号按 §2/§1 公式取整；分隔线恒 `hair`。
5. 除 `mark`（及 `dot` 微实心例外）外一律线性；禁止 `fill=<bg>` 伪造镂空、禁止为 hover 重绘几何。
6. 图标 24×24 / 品牌盾 64×64 设计坐标，安全边距 2，统一 20×20 光学框；方端尖角，禁圆端圆角。
7. 不改 `src/`、`installer/`、`app/` 生产代码，不打包不部署；本阶段只出规范，不写 `icons.svg`、不做文案表。
8. 四个功能图标必须互不相同（`plane`/`pulse`/`shield`/`block`），`link` 不再复用。

**可协商（需 Phase 3 或主理人确认）**
1. 开关 `40×22 → 40×24`、行高 `48 → 40/56`，为对齐 8 栅格，需确认不破现有布局。
2. 头部按钮热区是否带 4px 圆角（需 arc 拼接，建议保持直角）。
3. `dot` 微实心例外是否改为 4×4 方点（视觉等价）。
