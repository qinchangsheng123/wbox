## 三阶段结论摘要

**视觉**：品牌盾是唯一实心图标，其余一律线性（`stroke=currentColor`），
`dot` 是直径 4 的微实心例外；图标不再用背景色伪造镂空，hover 只换颜色 token、不重绘几何 ——
这修掉了现有实现里「镂空填背景色、行 hover 后图标穿帮」的根因。
统一 24×24 设计坐标、20×20 光学框、安全边距 2、线宽 `round(1.8 × size/24)`、方端尖角；
10 个灰阶 token 原值不动，零彩色、零渐变、零阴影、直角（开关胶囊除外）。
品牌盾由「实心盾 + 背景色上箭头」改成三块实心 polygon + V 形双翼留白，
16px 下沟宽仍有 2px，且不再依赖底色。
四个功能图标拆开：`plane` 纸飞机 / `pulse` 屏内折线 / `shield` 六边盾加勾 / `block` 窗口加框外叉，
不再让小飞机与游戏加加共用同一个 `link`。
安装器弃用 `ttk.Style('vista')`，逐控件收敛到与面板同一套组件与 8px 栅格。

**文案**：六个内部名词退出界面（`config.json`、`plugins\`、`%LOCALAPPDATA%`、`.zip`、
`热重载`、`计划任务`），统一动词（停止守护 / 退出窗口 / 关闭面板 / 安装 / 卸载），
菜单项压到 4–6 字，Tooltip ≤ 2 行且不写实现；错误框一律「发生了什么 + 下一步」，
不再抛 `repr(e)`；安装器副标题改为插件无关的「按需启用功能，随时可以卸载。」，
按钮态「安装 → 安装中…（禁用）→ 完成 / 重试」。

## 预览自检结果

`assemble.py` 把两个成员片段拼成单页，校验：7 个视图齐全、23 个图标 symbol 与
23 处 `<use>` 引用全部匹配、0 个外部依赖、3 段脚本 `node --check` 全过、
无 `box-shadow` / 渐变 / 半透明遮罩（`border-radius` 仅 4 处，都是规范允许的开关胶囊与圆形滑块）。
用无头 Edge 实际渲染了 5 张图：浅色「设置面板 / 安装程序 / 图标板」、
深色「设置面板 / 文案对照」，布局无溢出、无空白断片、深浅主题对称。

改片段后重生成：`python design/v2-ui/assemble.py`。

## 已知偏差（留给你一起确认）

1. 图标板里 `ic-gear` 与 `ic-sun` 都是「圆 + 放射短线」，视觉偏接近；
   规范要求 gear 6 齿、sun 8 芒，落地前需要把两者拉开差距。
2. 面板窗口 mock 与安装器窗口 mock 的预览宽度不一致（约 540 / 470 px），
   真实落地时按 8px 栅格统一到 660 系列尺寸。
3. 安装器首屏「已找到 MSI Afterburner」的路径副行与「安装进度」间距偏紧，
   落地按 8px 栅格补齐。

这三条都是预览层的呈现偏差，不影响两份规范的结论；确认时可一并勾选是否修正。
